# Seguridad

No publiques claves privadas de firma (`.der`, `.pem`, `.key`), contrasenas o tokens, tampoco en issues ni capturas. El `.gitignore` reduce errores al usar Git, pero no protege archivos subidos manualmente desde el navegador.

Si encuentras una exposicion de datos, evita publicar el contenido. Utiliza un canal privado con el propietario del repositorio; si esta habilitada la opcion de reporte privado de vulnerabilidades en GitHub, usala. No hay todavia un correo de seguridad publico configurado.

Este es un prototipo sin soporte de seguridad garantizado. La ausencia de claves en este repositorio no implica que cualquier archivo local o historico de otro repositorio sea seguro para publicar.
